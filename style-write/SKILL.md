# /style-write — 按你的风格写文章

> 加载你训练好的风格档案，按"你的写法"生成短文。
> **承诺：训练 50 篇不会白费**。生成后自动验证风格还原度，不达标自动重写。

---

## 🛡️ 5 道质量保证护城河 + 自主进化

| # | 护城河 | 解决什么 |
|---|--------|---------|
| 0 | 🆕 **自主进化** | 每次生成前必须遍历 `results/终版/`（用户亲手定稿的成品）+ `difference/`（逐字对比出的作者偏好），让 AI 知道"什么能过关"和"别再犯什么错" |
| 1 | **检索要准** | 50 个样本里挑 3-5 个最相关的（按 `retrieval.md` 多路召回）|
| 2 | **档案翻译要硬** | 软描述 → 硬约束，分 🚨/🟡/🟢 三层 |
| 3 | **Prompt 组装要全** | 嵌入完整原文 + 特征签名 + 作者偏好逐字对照，不只是摘要 |
| 4 | **生成后要自动验证** | 7 维核对 + 反样本扫描 + **作者偏好核对** + 样本特征还原核对 |
| 5 | **偏离要自动修复** | 偏离 10-25% 自动改，>50% 自动重写，最多 2 次 |

> ⚠️ **绝不接受"档案是档案，生成是生成"**。如果最后生成结果和档案无关，这是一次失败的任务。
> 
> 🧬 **自主进化闭环**：AI 生成初版 → 用户微调出终版 → 逐字对比提炼偏好 → 下次生成自动注入。
> **同一个毛病不允许犯第二次**——difference/ 中出现 ≥2 次的偏好升级为 🚨 硬约束，违反即判定生成失败。

---

## 📂 文件命名规范（强制，不可自由发挥）

三个目录共用同一个唯一 id `result-{MMDD}`：

```
results/初版/result-{MMDD}_{中文标题}-初版.md     ← AI 生成，本 skill 负责写入
results/终版/result-{MMDD}_{中文标题}-终版.md     ← 用户微调后手动放入
difference/result-{MMDD}_差异对比.md              ← 终版对比流程的产物
```

| 字段 | 规则 | 示例 |
|------|------|------|
| `{MMDD}` | **生成当日日期**，月日各补零（`date +%m%d`）。这是唯一 id | `0820` |
| `{中文标题}` | 文章中文标题。**不用拼音、不用英文 slug、不用序号** | `在等一个最好的状态` |
| `-初版` / `-终版` | 固定后缀 | — |

完整示例：`results/初版/result-0820_在等一个最好的状态-初版.md`

根目录**不再直接存放文章**——所有产出必须落到 `初版/`、`终版/`、`difference/` 三个子目录之一。

## 🔄 终版对比流程（用户主动触发）

当用户说 **"对比终版"、"我改完了"、"终版放好了"、"提炼一下偏好"** 时，
**不要走写作流程**，改为读取并执行：

```
Read ~/.claude/skills/style-distiller/style-lib/prompts/compare.md
```

该流程会：
1. 按 `result-{MMDD}` 前缀配对 `results/初版/` 与 `results/终版/`
2. 逐字对比（细到单字增删、标点变动）
3. 提炼"用户为什么这么改"，写入 `difference/result-{MMDD}_差异对比.md`
4. 与历史偏好比对，重复出现的偏好升级为 🚨 硬约束

## 第三步：深度对话挖掘（核心）

> **宗旨**：每当用户表达一次自己的主观意见时，至少提出一个问题用于深入探讨这个话题。
> 目的不是收集参数，而是理解用户**真正想表达什么**——这样才能写到"像你"。

### 规则总览

| 规则 | 内容 |
|------|------|
| **逐层提问** | 一次只问一个问题，不做信息轰炸 |
| **动机优先** | Q1 固定问主题，Q2 开始重点挖掘"为什么写" |
| **跟随主观意见** | 用户每表达一次主观意见 → 至少追问 1 个深入问题 |
| **零压力** | 每个问题末尾标注"（可以不回答，说'跳过'就行）" |
| **上限保护** | 最多 8 个问题，到达后自动进入生成 |
| **随时终止** | 用户说"开始写吧"/"够了"/"可以写了"/"生成吧"→ 立即进入 Phase 2 |

### 主观意见的识别信号

当用户表达以下内容时，视为"主观意见"，必须追问：
- "我觉得..." / "我认为..." / "我感觉..."
- "最触动我的是..." / "最让我难受的是..."
- "这个事让我意识到..."
- 用户给出具体案例/故事/场景
- 用户用了情绪化表达（"真的很烦" / "太爽了" / "搞不懂为什么"）

### 追问方向（按优先级）

| 优先级 | 方向 | 示例 |
|--------|------|------|
| 1 | **深挖动机** | "为什么这个点最触动你？" |
| 2 | **追问观点** | "那你觉得根本原因是什么？" |
| 3 | **追问细节** | "当时具体发生了什么？你第一反应是什么？" |
| 4 | **追问变化** | "这件事之后，你的想法/做法有变化吗？" |
| 5 | **追问对比** | "跟以前相比，你现在怎么看这件事？" |
| 6 | **追问反例** | "有没有相反的经历？或者你身边有人跟你看法不同吗？" |

**追问质量要求**：
- 问题必须基于用户刚说的内容，不能是模板化问题
- 要有"往下挖一层"的感觉，不能停留在表面
- 避免"你还有什么想说的吗"这类空洞问题

### Q1（固定）：主题

```
✍️ 这次想写什么？

一句话、几个关键词、或者一个你想探讨的问题都行。

（可以不回答，直接说"跳过"——我会用通用模式写）
```

### Q2（固定）：动机

```
💭 为什么想写这个？

比如：
- 最近发生了什么事让你有感而发？
- 你想通过这篇文章表达什么？
- 还是单纯想记录一下？

（可以不回答，说"跳过"就行）
```

### Q3-Qn（动态）：跟随主观意见

根据用户的回答，识别主观意见信号，选择一个追问方向深入提问。

**每个问题末尾必须带**：`（可以不回答，说"跳过"就行）`

### 终止条件

| 触发 | 行为 |
|------|------|
| 用户说"开始写吧"/"够了"/"可以写了"/"生成吧" | 立即进入"确认写作参数" |
| 问题数达到 8 个 | 告知用户"聊了 8 轮了，我先开始写"，进入"确认写作参数" |
| 用户连续 2 次说"跳过" | 判断用户不想深入，进入"确认写作参数" |
| 用户回答内容已足够丰富（3+ 个具体案例/观点） | 可问"要不要开始写了？"确认后进入"确认写作参数" |

### 对话结束后：整理"观点摘要"

将挖掘到的内容整理为结构化摘要，供 write.md 的 Step 4 注入 prompt：

```
📋 观点摘要（来自深度对话）
- 核心观点：{1-3 条}
- 具体案例：{用户分享的场景/经历，保留原话关键词}
- 情感基调：{克制/愤怒/释然/困惑/自嘲/...}
- 用户原话摘录：{2-3 句最有代表性的原话}
- 写作动机：{一句话总结}
```

### 确认写作参数（强制，不可跳过）

> ⚠️ 深度对话结束后，**必须先确认写作参数**，再进入 Phase 2。

```
✍️ 聊得很清楚了，最后确认三件事：

1️⃣ 文体
   - 散文体（默认，场景陈述+观点递进）
   - 对话体（两人问答形式）
   - 其他（你说）

2️⃣ 平台
   - 朋友圈（100-300字）
   - 小红书（300-800字）
   - 即刻（300-800字）
   - 公众号（800-1500字）

3️⃣ 调性（可选）
   - 克制 / 锋利 / 温柔 / 自嘲 / 冷幽默
   - 不指定就用档案默认

（不回答的话，默认：散文体 + 朋友圈短篇 + 档案默认调性）
```
