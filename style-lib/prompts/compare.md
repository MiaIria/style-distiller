# 终版对比流程（初版 → 终版 逐字差异提炼）

> **目的**：用户微调完初版后，逐字对比初版与终版，把"用户为什么这么改"提炼成可复用的作者偏好，
> 写入 `difference/`，供下次 `/style-write` 作为硬约束注入。
>
> 🧬 **这是整个自主进化闭环的关键一环**。没有这一步，用户的每次改稿都是一次性劳动。

---

## 触发条件

用户说以下任意一句，即进入本流程：
- "对比终版" / "对比一下" / "做个差异对比"
- "我改完了" / "终版放好了" / "最终版好了"
- "遍历最终版" / "提炼一下偏好"

用户可以指定 id（如"对比 result-0820"），也可以不指定（则自动扫描所有待对比项）。

---

## 三个目录的对应关系

```
results/初版/result-{MMDD}_{中文标题}-初版.md     ← AI 生成
results/终版/result-{MMDD}_{中文标题}-终版.md     ← 用户微调后放入
difference/result-{MMDD}_差异对比.md              ← 本流程的产物
```

`result-{MMDD}` 是贯穿三者的**唯一 id**。

---

## Step 1：扫描配对

```bash
ls ~/.claude/skills/style-distiller/style-write/results/初版/
ls ~/.claude/skills/style-distiller/style-write/results/终版/
ls ~/.claude/skills/style-distiller/style-write/difference/
```

**按 `result-{MMDD}` 前缀配对**，分类：

| 状态 | 条件 | 行为 |
|------|------|------|
| ✅ 待对比 | 初版有 + 终版有 + difference 没有 | **本次处理** |
| ⏭️ 已对比 | 三者都有 | 跳过（除非用户明确要求重做） |
| ⏳ 等待微调 | 只有初版 | 跳过，提示用户"这篇还没放终版" |
| ⚠️ 孤儿终版 | 只有终版 | 跳过，提示"找不到对应初版，无法对比" |

**输出扫描报告**：
```
🔍 扫描配对结果
  ✅ 待对比：{N} 篇
     - result-0820_中文标题
  ⏭️ 已对比：{N} 篇（跳过）
  ⏳ 等待微调：{N} 篇（只有初版）
  ⚠️ 孤儿终版：{N} 篇（找不到初版）
```

**边界情况**：
- 初版和终版的**中文标题不一致**（用户改了标题）→ 仍按 id 配对，并在差异文件里记录"标题也被改了"，这本身就是一条偏好
- 待对比为 0 篇 → 告知用户，不要空跑

---

## Step 2：逐字对比

对每一对初版/终版：

1. `Read` 两个文件的**完整正文**（跳过 frontmatter 和风格报告部分，只对比文章正文）
2. **按段落/对白顺序逐句比对**，找出所有差异点

### 差异点的判定粒度

> ⚠️ **粒度要细到"字"**。少一个"我"字、多一个"还"字，都是偏好信号。

| 差异类型 | 是否记录 | 说明 |
|---------|---------|------|
| 整段删除/新增 | ✅ 记录 | 结构级偏好 |
| 句子改写 | ✅ 记录 | 措辞级偏好 |
| 词语替换 | ✅ 记录 | 用词级偏好 |
| 增删单字（"我"/"还"/"连"） | ✅ 记录 | **最有价值的信号** |
| 标点变动 | ✅ 记录 | 节奏级偏好 |
| 纯错别字订正 | ❌ 不记录 | 不是风格偏好 |
| 段落顺序调整 | ✅ 记录 | 结构级偏好 |

### 对每个差异点，必须回答"为什么"

不要只列出"改了什么"，必须解释**用户为什么这么改**——这才是可复用的部分。

分析角度：
- 口语 vs 书面
- 陈述 vs 反问
- 具体 vs 概括
- 情绪浓度（加了还是减了）
- 距离感（拉近还是推远）
- 句子长度（变长还是变短）
- 与 `~/.claude/styles/profile/` 里 7 维档案的对应关系

---

## Step 3：写入 difference/

**文件名**（强制）：
```
~/.claude/skills/style-distiller/style-write/difference/result-{MMDD}_差异对比.md
```

`{MMDD}` 必须与初版/终版的 id 完全一致。

**写入前确认目录存在**：
```bash
mkdir -p ~/.claude/skills/style-distiller/style-write/difference
```

### 文件格式（严格遵守，供下次 write 解析）

```markdown
# 差异对比：result-{MMDD}_{中文标题}

> **对比对象**
> - 初版（AI 生成）：`results/初版/result-{MMDD}_{中文标题}-初版.md`
> - 终版（用户微调）：`results/终版/result-{MMDD}_{中文标题}-终版.md`
> - 对比时间：{YYYY-MM-DD}
> - 文体：{散文体/对话体} / {平台} / 约 {N} 字

---

## 逐字差异分析

### 1. {差异点小标题}

| 初版 | 终版 |
|------|------|
| "{初版原句}" | "{终版原句}" |

**偏好说明**：{为什么这么改。要具体、要讲清楚背后的表达逻辑，不要说套话}

---

### 2. {差异点小标题}

...（每个差异点一节）

---

## 表达偏好总结

| # | 偏好 | 具体表现 |
|---|------|---------|
| 1 | **{偏好名，加粗}** | {在本文里怎么体现的} |
| 2 | ... | ... |

---

## 核心洞察

{一段话，总结这次改动的本质规律——是内容问题还是措辞问题？暴露了 AI 的哪个系统性毛病？}

下次 `/style-write` 生成时，这 {N} 条偏好应作为强约束注入 prompt。
```

> 📌 **「表达偏好总结」表格是下次 write 直接读取的部分**，必须存在，且每条偏好要写成"可执行的规则"，
> 不能写成"要写得更好"这种没法执行的话。

---

## Step 4：汇报

```
✅ 差异对比完成

📂 已写入：difference/result-{MMDD}_差异对比.md

📊 本次提炼
  ├ 差异点：{N} 处
  ├ 表达偏好：{M} 条
  └ 核心洞察：{一句话}

🧬 新增的高频偏好（在历史 difference 中也出现过，将升级为硬约束）：
  - {偏好}（累计 {N} 次）

下次 /style-write 会自动加载这 {M} 条偏好。
```

如果本次提炼的偏好与历史 difference 中的**重复**，明确指出——重复出现意味着 AI 在同一个地方犯错第二次，
应在汇报里点名，并提示"这条偏好将升级为 🚨 硬约束"。

---

## 边界情况

| 情况 | 处理 |
|------|------|
| 初版与终版**完全相同** | 不生成 difference 文件，告知"这篇你没改动，无偏好可提炼" |
| 差异极大（终版重写了 >70%） | 照常提炼，但在核心洞察里明确标注"初版基本被推翻，说明 {某维度} 档案有系统性问题"，并建议 `/style-review` |
| 终版文件带 frontmatter | 只对比正文，frontmatter 的变动单独记为元数据变更，不计入风格偏好 |
| 用户一次放了多篇终版 | 逐篇处理，每篇一个 difference 文件，最后汇总汇报 |
